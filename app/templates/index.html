    ¿Qué es SMIP?

    SMIP es una aplicación web académica desarrollada con Python 3.12, FastAPI y Uvicorn.

    Funcionalidades disponibles en esta fase:

    • 📤 Carga de archivos (upload) — POST /upload
    • 📥 Descarga de archivos (download) — GET /download/{nombre}
    • 📋 Listado de archivos — GET /files
    • ✉️ Envío de correos (SMTP) — POST /send-email

    Actualmente en Fase 3 — subida, descarga, listado y envío de correos implementados. Para usar el envío de correos, configura las variables SMTP_HOST, SMTP_PORT, SMTP_USER, SMTP_PASSWORD y SMTP_FROM (ver .env.example).
