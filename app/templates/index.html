    ¿Qué es SMIP?

    SMIP es una aplicación web académica desarrollada con Python 3.12, FastAPI y Uvicorn.

    Funcionalidades disponibles en esta fase:

    • 📤 Carga de archivos — POST /upload
    • 📥 Descarga de archivos — GET /download/{nombre}
    • 📋 Listado de archivos — GET /files
    • ✉️ Envío de correos (SendGrid) — POST /send-email
    • 💾 Persistencia de archivos (Supabase Storage)

    Actualmente en Fase 3 — subida, descarga, listado, envío de correos con SendGrid API y persistencia de archivos con Supabase Storage.
